# Publicaciones del Estudio Delpin Pizarro & Cía.

Sitio estático que sirve las piezas completas de los boletines del Estudio en `publicaciones.delpinpizarro.cl` (GitHub Pages).

- `index.html`: índice de piezas.
- `boletin-colegios/AAAA-MM/<slug>.html`: una página por pieza del Boletín para colegios.
- `plantillas/pieza.html`: plantilla de la pieza completa (una columna, marca, claro y oscuro).
- `assets/`: logotipos y fotografías del kit.
- `CNAME`: dominio personalizado.

Publicar: dejar la página en su carpeta, agregarla al índice, `git add -A && git commit && git push`. GitHub Pages la sirve en uno o dos minutos.

Reglas de contenido: manual editorial en `8. Publicaciones/0. Manual editorial/` del OneDrive del Estudio. Nada se publica sin verificación de fuentes.
